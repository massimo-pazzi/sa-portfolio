# Тест-кейсы видеоконтура

[← к кейсу](../README.md) · [трассировка](traceability.md)

Тест-кейсы собраны из браузерных сценариев приёмки и тестовой стратегии.

Сценарии задают приёмку проектного решения. Результаты выполнения фиксируются отдельно в протоколе испытаний. Обозначение BR или NFR в последнем столбце ссылается на соответствующее правило вне выдержки FR.

| ID | Сценарий | Ожидаемый результат | Связь с требованиями |
|---|---|---|---|
| TC-1 | Открыть рецепт из ленты | постер, заголовок, ингредиенты, шаги и КБЖУ видны сразу; комментарии и «Похожие» появляются после скелетонов | FR-1 |
| TC-2 | Сломать одну второстепенную секцию | рецепт открывается, на месте секции — локальная ошибка | FR-1 |
| TC-3 | Автор меняет рецепт в консоли, зритель обновляет страницу | изменения видны на следующем запросе | FR-2 |
| TC-4 | Навести на карточку, затем открыть рецепт | рецепт открывается без запроса к серверу | BR-1 |
| TC-5 | Открыть рецепт с видео | постер сразу, затем адаптивный плеер; код плеера загружается только здесь | FR-1 |
| TC-6 | Меню качества | «Авто» и ручной выбор каждого уровня | FR-5 |
| TC-7 | Элементы плеера | есть «картинка в картинке», нет «скачать» | BR-2 |
| TC-8 | Нарезка вертикального видео ниже 720 и видео 1080p | создаются профили до 1080/720/480 с сохранением пропорций, без увеличения разрешения исходника | FR-3 |
| TC-9 | Нарезка падает | задача FAILED с текстом ошибки, автор видит «не удалось обработать» и повтор | FR-3, FR-4 |
| TC-10 | Участник клуба смотрит видео REGISTERED-рецепта | плейлисты идут через маршрут приложения, сегменты — по подписи, видео играет | FR-6 |
| TC-11 | Анонимный прямой запрос к плейлисту, сегменту и фото шага в хранилище | 403; несуществующий ключ в закрытом префиксе — тоже 403, не 404 | FR-6, BR-3 |
| TC-12 | Анонимный запрос к обложке, лого, аватару | 200 | BR-3 |
| TC-13 | Подписчик без подписки открывает PRO-рецепт | постер; элемента видео и ссылки на плейлист в странице нет | FR-11 |
| TC-14 | Подписчик открывает рецепт с фото шагов | фото шагов загружаются по подписанным ссылкам | BR-3 |
| TC-15 | Просмотр дольше 15 минут (~18 минут) без обновления страницы | после 403 на сегменте плеер перезапрашивает плейлист и продолжает с той же позиции | FR-8 |
| TC-16 | Подписанная ссылка со сроком 1 с через 3 с | 403 | NFR-5 |
| TC-17 | Право отозвано между двумя запросами плейлиста, второй — из кэша | 403: право проверяется и на кэшированном чтении | FR-6 |
| TC-18 | Два запроса подряд | хранилище прочитано один раз, подписи разные; в кэше нет `X-Amz-` | FR-7 |
| TC-19 | Запрос ключа чужого клуба или оригинала | ключ пропущен, подпись не выдана | FR-6, BR-3 |
| TC-20 | Больше 100 запросов в минуту от одного пользователя | 429 | BR-3 |
| TC-21 | Автор размечает отрезок шага: начало и конец кнопками и вводом мм:сс; пытается поставить конец раньше начала | отрезок сохраняется; некорректный — отклоняется; при фото шага кнопка отрезка недоступна | BR-4 |
| TC-22 | Кнопка «Рецепты» в боте Telegram → вход по e-mail → открыть рецепт с видео | клуб открывается во встроенном браузере, видео играет внутри страницы, бесшовная переподпись работает | BR-5, FR-8 |
| TC-23 | То же в Max | то же | BR-5, FR-8 |
| TC-24 | Очистка «сирот» на общем бакете, объект есть только в базе стейджа | объект не удаляется | BR-6 |
| TC-25 | Удалить объект в бакете резерва ключом резервного копирования | AccessDenied | BR-6 |
| TC-26 | Удалить HLS рецепта в бакете показа и восстановить из оригиналов | видео снова играет | NFR-10, BR-6 |

## Дополнительные сценарии приёмки

| ID | Сценарий | Ожидаемый результат | Связь с требованиями |
|---|---|---|---|
| TC-27 | Опубликовать рецепт в PENDING; открыть видео; дождаться DONE и открыть повторно | исходник доступен только через маршрут с правом и Range; повторное открытие использует HLS; текущий просмотр не обрывается | FR-4 |
| TC-28 | Ухудшить и восстановить канал во время просмотра | качество автоматически меняется; ручной выбор и возврат в «Авто» работают | FR-5, NFR-2 |
| TC-29 | Открыть шаг с отрезком 75–100 с, дождаться конца, нажать «Повторить» | старт с 75 с, остановка на 100 с, повтор с 75 с | FR-12 |
| TC-30 | Перейти вперёд и назад кнопками и свайпами | текст и видео соответствуют шагу; запуск с его начального таймкода | FR-9 |
| TC-31 | Открыть первый, последний и единственный шаг; завершить готовку | назад за первый шаг перейти нельзя; завершение возвращает на страницу рецепта | FR-10 |
| TC-32 | Создать, изменить и удалить рецепт при прогретом кэше | следующий запрос соответствующей поверхности отражает изменение | FR-2 |
| TC-33 | Запросить плейлист без сессии, без права и при отказе проверки | 401, 403 и 5xx соответственно; подписей в ответах нет | FR-6 |
| TC-34 | Открыть PRO-рецепт анонимно и участником без подписки; нажать оформление | доступны только открытые данные и переход к оформлению, платные медиа не выдаются | FR-11 |
| TC-35 | Открыть страницу двумя пользователями с разными правами | общий кэш не содержит подписей; подписи получает только пользователь с правом | FR-7 |
| TC-36 | Пауза дольше TTL, возобновление; затем отзыв права | позиция сохраняется при обновлении ссылки; после отказа новый доступ не выдаётся | FR-8 |
| TC-37 | Прогнать согласованный профиль нагрузки и сети | измерены p95 первого кадра, ответа плейлиста, буферизация и время до DONE по порогам НФТ | NFR-1, NFR-2, NFR-3, NFR-4, NFR-7 |
| TC-38 | Потерять сервер до и после сохранения оригинала; восстановить из резерва | границы устойчивой записи соблюдены; RPO и RTO измерены по НФТ | NFR-8, NFR-9, NFR-10 |
| TC-39 | Проверить TTL сегмента 900 с, фото 3600 с и исключение админа 21600 с; прекратить подписку | новая подпись после прекращения права не выдаётся; ранее выданные URL действуют только до своего срока; скачанные байты не отзываются | NFR-5, NFR-6 |
| TC-40 | Подать отчёт по объёму хранения и месячному трафику 40/50 ГБ | на 40 ГБ срабатывает предупреждение; после 50 ГБ формируется основание подключения CDN с сохранением защиты | BR-7 |

[Приёмка наблюдаемости](../requirements/04-observability.md#приёмка) проверяет метрики, алерты и безопасную эксплуатацию.
